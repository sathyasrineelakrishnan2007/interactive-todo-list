
# Interactive To-Do List with LocalStorage

## Project Description
This project is an interactive To-Do List web application developed using HTML, CSS, and JavaScript. It helps users add, complete, and delete tasks easily. Tasks are saved in the browser using LocalStorage, so they remain available after refreshing the page.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Key Features
- **Add Tasks:** Add new tasks using the Add Task button.
- **Enter Key Support:** Add tasks by pressing the Enter key.
- **Mark as Complete:** Mark tasks as completed or undo completion.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **LocalStorage:** Save tasks in the browser automatically.
- **Task Progress:** Display completed tasks and total tasks.
- **Responsive Design:** Works on mobile phones and desktop screens.
- **Dynamic Updates:** Update the task list using JavaScript DOM manipulation.

## How to Run
1. Clone or download this repository.
2. Open the `index.html` file in a web browser.
3. Enter a task in the input box.
4. Click **Add Task** or press **Enter**.
5. Mark tasks as complete or delete them when needed.
6. Refresh the page to verify that tasks are saved.
